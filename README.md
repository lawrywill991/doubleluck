# INTRODUCTION
This project is a Web-based internal management system developed for "好勢成雙林園". It currently features a secure login system alongside comprehensive employee profiles and work hour tracking.

Additional features are actively under development, including financial management, order processing, and customer relationship management (CRM) modules.

## Tech Stack
- Backend: Python (Flask, SQLite)
- Frontend: HTML, CSS, JavaScript

# FEATURES
* 🔒 **User Authentication**: Secure login system for internal staff.
* 👥 **Employee Management**: Record employee profiles and track work durations.
* ⏳ **Upcoming Features**: Financial tracking, order management, and CRM.
